- 教學對象：九年級自然（理化），一般生＋數理資優生共用同一份網頁；也給學生自學、複習
- 使用情境：課堂投影授課＋學生用手機/平板自學
- 右上角三種模式：**學生**（預設，自學用）／**資優**（展開紫色資優挑戰）／**老師**（再加教學提示與舉手計數）
- g 值切換：9.8 或 10（所有計算、例題跟著變）

## 重要規則
- 老師要求：**例子、影片、情境模擬要多**（第 1 批回饋）。第 2、3 批也照這個豐富度。
- 影片資料在 `src/ch3/js/02_videos.js`（來源 `research/videos.json`，oembed 驗證）；已排除 Walter Lewin 的影片。
- **練習題不可使用老師的段考題庫原題**（`段考題資料庫/02_國中段考題庫/國三上/第二次段考_理化_CH2力與運動_CH3功與能/`）。可參考題型，但要換情境＋換問法＋換數字，並做相似度比對。
- 歷屆會考題可直接用，標出處。
- 科學史、案例數據已查證，見 `research/ch3_資源查證.md`（查證日 2026-10-12）。

## 怎麼改內容
1. 改 `src/` 底下的零件（不要直接改輸出的 HTML）：
   - `src/common/style.css`、`core.js`（由地科版改來：三種模式、g 值）、`extra.js`（例題逐步揭曉、隨堂筆記空格、學習 Check、時間軸、延伸資源、能量長條圖）
   - `src/ch3/tabs/t0.html …`：每個分頁（第一行 `<!--NAV: 標題-->` 是分頁按鈕名字）
   - `src/ch3/js/00_data.js`：時間軸、猜一猜、迷思擂台；`01_res.js`：延伸資源連結；`t0.js …`：各分頁模擬
2. 重新組合：`cd src && python3 build.py ch3` → 產生 `第三章_功與能_互動課本.html` 與 `ch3.html`（會自動跑 make_qbank.py 把 research/*.json 題庫轉成 03_qbank.js）
   - 題庫改了之後，要重做下載檔：`cd src && python3 make_downloads.py`（需要 Google Chrome、python-docx），再 build 一次
   - 學習單內容在 `src/worksheets.py`
3. 預覽：Claude 的 launch.json 有 `phy-textbook`（port 8771）
